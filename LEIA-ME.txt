ALLYHUB v1.0 - biblioteca de jogos + perfis de desempenho para o ROG Ally
==========================================================================

NOVIDADES
- Ecra de arranque animado (podes trocar por uma imagem tua: poe um splash.png
  ao lado do AllyHub.exe).
- Interface nova: o fundo mostra a arte do jogo selecionado, carrossel de capas
  que crescem e brilham, medidor de TDP, relogio e bateria.
- Botao "Arranca com o Windows": abre a AllyHub sozinha quando ligas o Ally.
- Atualizacoes automaticas a partir do GitHub.


PASSO 1 - GITHUB (ja esta feito)
--------------------------------
Repositorio: https://github.com/bba219187-droid/AllyHub
Cada push para main compila o AllyHub.exe e publica-o em "Releases".


PASSO 2 - INSTALAR NO ALLY (uma vez so)
---------------------------------------
1. Cria uma pasta, por exemplo C:\AllyHub, e descarrega para la o AllyHub.exe
   do release.
2. Descarrega o ZIP para Windows do RyzenAdj
   (https://github.com/FlyGoat/RyzenAdj/releases) e copia TODOS os ficheiros
   para a mesma pasta. Sem ele, a app funciona so como biblioteca.
   Atencao: o driver do RyzenAdj pode ser marcado pelo Windows Defender ou
   por anti-cheats.
3. Abre o AllyHub.exe, aceita o pedido de administrador e carrega em
   "Arranca com o Windows" no canto superior direito.


COMO LANCAR UMA ATUALIZACAO
---------------------------
1. Muda o codigo.
2. Em AllyHub.csproj sobe o numero em <Version> (ex.: 1.0.0 -> 1.0.1).
3. git commit -am "o que mudaste"  e  git push
Da proxima vez que o Ally abrir a AllyHub, ela descarrega a versao nova,
substitui-se e reinicia sozinha.


CONTROLOS (v1.1)
----------------
Biblioteca:  esquerda/direita = jogo      A = jogar         MENU = detalhes
             cima/baixo = +/- 1 W         LB/RB = perfil    VIEW = Booster
             LT/RT = filtro (Todos, Favoritos, Recentes, lojas)
             X = favorito   Y = Sistema   B = atualizar a lista
Em jogo:     VIEW + MENU ao mesmo tempo (ou Ctrl+Shift+A) = menu rapido
Paineis:     setas = escolher   A = confirmar   B = voltar
Ecra:        toca num jogo para o escolher e toca outra vez para jogar.
Teclado:     setas, Enter, Tab (filtro), F (favorito), D (detalhes),
             S (sistema), B (booster), F5, Esc.

NOVO NA v1.2
------------
- Controlo das ventoinhas (Sistema ou menu rapido): Automatico (ASUS),
  Silencioso, Equilibrado, Desempenho, Maximo. Em todos os perfis a
  ventoinha vai a 100% quando o CPU passa dos 90 C. Ao fechar a AllyHub
  as ventoinhas voltam ao automatico da ASUS.
- Modo de testes (Sistema ou tecla T): comando, vibracao, cores do ecra,
  ecra tatil, colunas, ventoinhas, stress de 60 s com temperaturas,
  saude da bateria, memoria e armazenamento.
- Atualizador corrigido: mostra a percentagem do download.

NOVO NA v1.1
------------
- Ecra "A abrir" por cima da Steam ate a janela do jogo aparecer.
- Tempo de jogo, ultima vez jogado, favoritos, recentes e filtros.
- Ubisoft Connect e jogos adicionados a mao (.exe) - em Sistema.
- Ecra de detalhes de cada jogo.
- Menu rapido em jogo: TDP, perfil, Booster, temperatura, potencia, bateria.
- Modo Booster (com termos): TDP maximo da ASUS + plano "Melhor desempenho".
- Sistema: BIOS, driver da GPU, atualizacoes pendentes do Windows Update
  (inclui drivers), atalho para o Update Center do Armoury Crate.
- Temas de cor, sons de navegacao, animacoes novas.
- Volta sozinha a AllyHub quando fechas o jogo.

Os perfis, tempos de jogo e o TDP de cada jogo ficam em
%AppData%\AllyHub\config.json. 30 W so ligado a corrente.
